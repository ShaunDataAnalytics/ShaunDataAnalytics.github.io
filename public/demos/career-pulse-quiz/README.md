## 🔧 如何替换你的真实问卷链接与群二维码？

打开 `js/quiz-data.js` 文件，拉到最底部的 `nextStep` 配置项：

1. **替换问卷预约链接**：
   将 `buttonUrl: "https://your-domain.com/survey-booking"` 中的网址替换为你的问卷星、腾讯文档或飞书表单链接。
2. **替换真实的微信群二维码图片**：
   直接将你的微信群二维码图片命名为 `group-qr.png` 放到 `assets/` 文件夹下，然后把 `nextStep` 中的 `qrCodeImg` 改为 `"assets/group-qr.png"` 即可！

## 📱 步骤四：手机实机检查清单（真机上线前必看）

由于手机浏览器环境多样，部署上线后请用真实手机按照以下清单快速走一遍：

1. **流畅答题**：从第一题点击到最后一题，检查字号是否清晰（确保不小于 16px），选项卡片是否整块容易按压。
2. **返回修改**：点击“上一题”，确认已选过的选项被完整保留。
3. **刷新恢复**：答到第 3 题时下拉刷新页面，确认页面能够精准恢复至第 3 题。
4. **生成海报**：在结果页点击「📸 生成高清分享海报」，检查弹出的 1080×1440 竖版图片：
   - 中文文字是否有被截断或挤在一起；
   - 海报短金句是否清晰有力；
   - 右下角二维码是否能用微信/相机正常扫出。
5. **保存相册**：
   - 长按弹出的图片，在手机弹出的菜单中选择「保存到相册」，检查相册中图片是否完整清晰。
   - 点击「复制邀请文案与测试链接」，粘贴到微信聊天框看格式是否友好。
